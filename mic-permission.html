🎙 Microphone access for Live Translate

Live Translate listens to the audio you choose and speaks the translation. The browser asks for microphone permission once per extension — the popup is too small a window to ask from, so this page does it.

  1. Click the padlock (or Brave lion) icon left of the address bar → Site settings → set Microphone to Allow, then reload this page and click the button again.
  2. Brave: also check brave://settings/content/microphone — this page's address must not be under "Not allowed".
  3. macOS: System Settings → Privacy & Security → Microphone — your browser must be enabled there too.
